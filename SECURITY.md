# Security policy

This integration stores a Bluetooth key that can lock and unlock a car, so please report problems privately.

To report a vulnerability, use GitHub's
[private vulnerability reporting](https://github.com/mjens118/hass-byd-ble/security/advisories/new)
for this repository. Please do not open a public issue for anything that exposes a key or lets someone
unlock a car without one.

Never post a `credentials.json`, a `dkey`, diagnostics you have not checked, or your car's Bluetooth
address in an issue. Diagnostics from this integration redact the key, the "watch" identity, the lock code
and the address, but look before you attach.

This is a hobby project with one maintainer. I will respond when I can and will credit reporters who want it.
